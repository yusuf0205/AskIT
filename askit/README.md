# AskIT Frontend Web Application

React web application featuring user registration, profile management, interactive content cards, and navigation popups (skit/).

## Components

| Path | Description |
| :--- | :--- |
| skit/src/Component/Regist/regist.jsx | User registration and sign-in form |
| skit/src/Component/Profile/profile.jsx | User profile view and account details |
| skit/src/Component/Card/card.jsx | Dynamic data-driven card grid backed by data.json |
| skit/src/Component/Navbar-test/ | Navigation bar with language selector (Language.jsx), notifications (Notification.jsx), and support modal (support.jsx) |

## Getting Started

`ash
cd askit
npm install
npm start
`
