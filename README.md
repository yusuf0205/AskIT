# AskIT Frontend Web Application

React web application featuring user registration, profile management, interactive content cards, and navigation popups (`askit/`).

## Components

| Path | Description |
| :--- | :--- |
| `askit/src/Component/Regist/regist.jsx` | User registration and sign-in form |
| `askit/src/Component/Profile/profile.jsx` | User profile view and account details |
| `askit/src/Component/Card/card.jsx` | Dynamic data-driven card grid backed by `data.json` |
| `askit/src/Component/Navbar-test/` | Navigation bar with language selector (`Language.jsx`), notifications (`Notification.jsx`), and support modal (`support.jsx`) |

## Getting Started

```bash
cd askit
npm install
npm start
```
